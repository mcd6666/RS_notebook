# 高分影像几何校正与自动 PIF 大气校正批处理原理

本文说明当前批处理程序的主要处理思路，包括几何校正、自动伪不变地物筛选和基于 Sentinel-2 参考影像的相对辐射校正。

## 1. 总体流程

当前批处理流程分为两个阶段：

```text
高分融合/重命名影像（使用我们的原理的reg_dir的程序，重命名使用原来的脚本即可或者手动更改）
        |
        v
几何校正
        |
        v
高分正射影像 *_ORTHO.TIF
        |
        v
自动 PIF 大气/相对辐射校正
        |
        v
最终校正结果 *_RRC.TIF
```

其中：

```text
*_ORTHO.TIF  为几何正射校正结果
*_RRC.TIF    为基于 Sentinel-2 参考影像校正后的最终结果
```

## 2. 几何校正原理

几何校正阶段以已经融合、重命名后的高分影像为输入，例如：

```text
GF1B_..._HRMS_REG.TIF
GF2_..._HRMS_REG.TIF
GF6_..._HRMS_REG.TIF
```

程序会自动扫描输入目录，查找符合命名规则的高分影像。然后结合 Sentinel-2 参考影像和 DEM，调用已有的几何处理程序：

```text
satellite-geom.exe
ba.exe
```

### 2.1 控制点匹配

几何处理首先调用 `satellite-geom.exe` 进行影像匹配，匹配分为两步：

```text
多景联合匹配
单景参考匹配
```

多景联合匹配用于在多景高分影像之间建立初始控制点关系。单景参考匹配则逐景将高分影像与 Sentinel-2 参考影像进行匹配，补充和优化控制点。

匹配结果会生成控制点文件，用于后续平差。

### 2.2 平差

控制点生成后，程序调用 `ba.exe` 进行平差。平差的作用是利用控制点和 DEM 优化影像几何模型，减少影像间和影像与参考数据之间的几何偏差。

### 2.3 正射校正

平差完成后，程序再次调用 `satellite-geom.exe`，结合 DEM 和优化后的模型文件，对高分影像进行正射校正，输出：

```text
*_ORTHO.TIF
```

输出分辨率根据卫星类型自动判断，例如：

```text
GF1 / GF6      2 m
GF2 / GF7      0.8 m
Superview      0.5 m
GF WFV         16 m
```

如果参数中设置：

```text
PRJ=ref
```

则几何校正结果会使用 Sentinel-2 参考影像的投影。

## 3. 大气/相对辐射校正原理

当前程序中的“大气校正”不是严格的物理大气校正，而是基于 Sentinel-2 参考影像和伪不变地物的相对辐射归一化。

其核心思想是：

```text
以 Sentinel-2 影像作为参考，将高分影像校正到 Sentinel-2 的反射率体系中。
```

校正关系采用线性模型：

```text
Sentinel-2_band = slope * GF_band + intercept
```

其中：

```text
GF_band          为高分影像某一波段的原始或正射后数值
Sentinel-2_band  为 Sentinel-2 参考影像对应波段的反射率值
slope            为线性斜率
intercept        为线性截距
```

拟合得到 `slope` 和 `intercept` 后，程序将该关系应用到整景高分正射影像，生成最终校正结果。

## 4. 空间重叠与采样

大气校正首先计算高分正射影像与 Sentinel-2 参考影像的空间重叠范围。随后程序将两者临时对齐到同一参考网格，以便进行逐像元比较。

为了提高处理速度，拟合阶段不会总是使用全分辨率重叠区，而是通过参数 `SAMPLE_STEP` 进行采样。

例如：

```text
SAMPLE_STEP=4    每 4 x 4 像元取 1 个样本
SAMPLE_STEP=8    每 8 x 8 像元取 1 个样本
SAMPLE_STEP=16   每 16 x 16 像元取 1 个样本
```

如果 Sentinel-2 分辨率为 10 m，则大致对应：

```text
SAMPLE_STEP=4    约 40 m 间隔取样
SAMPLE_STEP=8    约 80 m 间隔取样
SAMPLE_STEP=16   约 160 m 间隔取样
```

`SAMPLE_STEP` 只影响拟合样本的密度，不改变最终输出影像的分辨率。

## 5. 候选像元初筛

在重叠区内，程序首先根据光谱指标筛选较可能稳定的候选像元。主要使用：

```text
NDVI
NDWI
亮度分位数
```

其中：

```text
NDVI = (NIR - Red) / (NIR + Red)
NDWI = (Green - NIR) / (Green + NIR)
Brightness = Blue + Green + Red + NIR
```

筛选目标是排除：

```text
水体
强植被
阴影
过亮或异常像元
```

保留更可能稳定的地物，例如：

```text
建筑物
道路
裸地
硬化地表
```

这些地物在不同时间或不同传感器影像中相对稳定，更适合作为伪不变地物候选。

## 6. 自动 ROI 筛选

传统人工流程中，通常需要人工在影像上选择一块稳定城区或裸地区域作为 ROI。当前程序将这一步自动化。

程序会将重叠区划分为若干网格块，并计算每个网格块内：

```text
候选像元比例
GF 与 Sentinel-2 的多波段差异稳定性
```

然后优先选择：

```text
候选像元多
多波段差异小
整体更稳定
```

的网格块作为自动 ROI。

相关参数包括：

```text
ROI_TILE_SIZE     网格块大小
ROI_TOP_PERCENT   保留稳定性排名靠前的比例
ROI_MAX_TILES     最多保留多少个 ROI 网格块
```

这一步相当于用程序模拟人工选择稳定城区 ROI 的过程。

## 7. 伪不变地物 PIF 筛选

在自动 ROI 内，程序进一步计算高分影像与 Sentinel-2 影像的多波段变化分数。

变化分数越低，说明该像元在两幅影像之间越稳定。程序选择变化分数最低的一批像元作为伪不变地物 PIF。

相关参数为：

```text
PIF_PERCENTILE
```

例如：

```text
PIF_PERCENTILE=5
```

表示从候选像元中选取变化分数最低的 5% 作为 PIF。

## 8. 鲁棒线性回归

选出 PIF 后，程序对每个波段分别建立线性关系：

```text
Sentinel-2_band = slope * GF_band + intercept
```

拟合过程中使用鲁棒迭代方法，自动剔除残差异常的像元，避免少量异常点影响整体校正系数。

最终每个波段会得到：

```text
slope
intercept
R2
RMSE
PIF 像元数
```

这些指标会写入 JSON 报告。

## 9. 整景应用

得到每个波段的线性校正关系后，程序将其应用到整景高分正射影像：

```text
GF_corrected_band = slope * GF_band + intercept
```

最终输出：

```text
*_RRC.TIF
```

该结果表示高分影像已经被归一化到 Sentinel-2 参考影像的反射率水平。

## 10. 质量评价

每景处理完成后，程序会生成：

```text
*_RRC_pif_report.json
```

其中主要字段包括：

```text
candidate_pixels    初筛候选像元数
roi_candidate_pixels 自动 ROI 内候选像元数
pif_pixels          最终 PIF 像元数
slope               各波段斜率
intercept           各波段截距
r2                  拟合优度
rmse                均方根误差
n_pixels            参与拟合的像元数
```

一般判断标准为：

```text
PIF 像元数越多，拟合越稳定
R2 越接近 1，线性关系越好
RMSE 越小，PIF 上的残差越小
```

需要注意，报告中的 RMSE 是在归一化反射率尺度上计算的。例如：

```text
RMSE = 0.002
```

若 `SCALE=10000`，则对应到整数反射率尺度约为：

```text
0.002 * 10000 = 20
```

## 11. 当前方法特点

当前方法与原人工流程的关系如下：

```text
原人工流程：
人工选择稳定 ROI -> iMAD/PIF 筛选 -> 线性校正

当前自动流程：
自动选择稳定 ROI -> 自动 PIF 筛选 -> 鲁棒线性校正
```

二者核心思想一致，都是利用 Sentinel-2 参考影像和伪不变地物，将高分影像校正到参考影像的反射率体系中。

当前方法的优点是：

```text
不需要人工选择 ROI
适合批量处理
每景都有质量报告
处理过程可重复
```

需要注意的是：

```text
它属于相对辐射归一化，不是严格物理大气校正
结果质量依赖 Sentinel-2 参考影像质量
结果质量依赖 GF 与 Sentinel-2 的时间差和地物变化情况
云、阴影、水体、农田变化会影响 PIF 筛选
```

因此，正式生产时仍建议检查：

```text
输出影像是否过亮或过暗
是否存在大片饱和
水体、建筑、植被光谱曲线是否合理
JSON 报告中的 R2、RMSE 和 PIF 像元数是否稳定
```
